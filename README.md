# Mr.ǰarvis Website — v2 Motion Edition

A responsive, dark-themed landing page for the Mr.ǰarvis student community.

## Features
- Responsive layout for desktop and mobile
- Scroll reveal animations and smooth navigation
- Animated ambient glows, gradient typography, and floating hero cards
- 3D tilt interactions and pointer-following card glow on desktop
- Custom glowing cursor on mouse/trackpad devices; standard cursor remains on touch devices
- Reduced-motion accessibility support
- No build step or package installation required

## Run locally
Open `index.html` in a browser. Keep `style.css` and `script.js` in the same folder.

## Deploy
Upload the four project files to a GitHub repository and import that repository into Vercel. This is a static website and requires no build command.

## Note
The page is a landing-page prototype. Login, application submission, database, coordinator dashboards, admin tools, and stipend tracking are not connected yet.
